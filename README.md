# django basic app

Django learning project with template-based login, signup, user, and project pages.

## Project scope

The current views render login, signup, user, and project templates. These pages are learning examples; the view functions do not implement a complete authentication or project-management workflow. A pinned Python dependency manifest still needs to be added before setup is reproducible.

## Project entry point

The Django management script is [ecommerce/manage.py](ecommerce/manage.py). Configure a Python environment and compatible Django dependency before using its management commands.
